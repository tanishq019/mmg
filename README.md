# Machine Magnet

Static website for NIET's Machine Magnet technical innovation club.

## Run locally

Serve the repository with any static server, then open the shown address in a browser. For example, with Python installed:

```powershell
python -m http.server 8080
```

Open `http://localhost:8080`.

The original one-file prototype has been split by responsibility. See [the architecture guide](docs/ARCHITECTURE.md) for the file map and a safe editing guide.
